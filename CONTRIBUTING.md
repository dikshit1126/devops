# Contributing Guide

## Workflow

1. Create or pick an issue
2. Branch from `develop`
3. Keep commits small and meaningful
4. Open a pull request into `develop`
5. Merge to `main` after review and CI success

## Branch Naming

- `feature/<name>`
- `fix/<name>`
- `hotfix/<name>`

## Commit Style

Use clear commit prefixes:

- `feat:`
- `fix:`
- `test:`
- `build:`
- `ci:`
- `deploy:`
- `infra:`
- `docs:`

## Review Expectations

- Link the related issue
- Confirm tests were run
- Request at least one review
- Update documentation when behavior changes
